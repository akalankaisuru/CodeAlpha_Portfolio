# CodeAlpha_Portfolio

Personal portfolio of Isuru Akalanka, QA Engineer and Software Engineering undergraduate.

## Features
- Interactive 3D background (Three.js) that morphs and changes color per section
- Step-by-step scroll animations (GSAP ScrollTrigger)
- Smooth scrolling, scroll progress bar, and animated counters
- Sections: About, Skills, Projects, Education, Contact
- Project video previews with a popup player
- Responsive layout with a mobile menu
- Downloadable CV

## Technologies
HTML5, CSS3, JavaScript, Three.js, GSAP
